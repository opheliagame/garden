まず、Lottieは何か

Lottieは、After EffectsのアニメーションをJSONデータとしてシリアライズし、アプリで再生できるファイル形式です。


名前の由来： ドイツのアニメーション作家、シャルロッテ・「ロッテ」・ライニガーに由来します。

Lottieは、After EffectsのアニメーションをJSONデータとしてシリアライズして、アプリで再生できるようにするファイル形式です。名前は、シルエットアニメーションの先駆者、ロッテ・ライニガーに由来します。

Lottieのざっくりした歴史

2015BodymovinがAfter EffectsのアニメーションをJSONに書き出す。
2017AirbnbがiOS、Android、React Native向けのライブラリを公開。
2018Microsoftと.NET FoundationがWindows向けライブラリを公開。
2019Qt、Samsung、Pythonなどにも対応が広がる。
2020複数のLottieと素材をまとめるdotLottieが登場。
2023ThorVGがLottieの描画に対応。
2024Lottie Animation Communityが形式の標準化を開始。
2015年にBodymovinがAfter EffectsからJSONを書き出せるようにしました。その後、Airbnbが各プラットフォーム向けのライブラリを作り、対応が広がりました。2020年にはdotLottieが登場し、今も形式の標準化が進んでいます。

dotlottie-flutter

LottieFilesという会社がオープンソースで開発

  • 🟢 .json 再生サポート
  • 🟢 .lottie 再生サポート
  • 🟢 .lottie ステートマシンサポート
JSONなら基本的な再生、.lottieなら複数の素材をまとめる用途に向いています。形式だけでなく、対応状況で選びます。

対応状況を確認する

サポートマトリックス

参考: Lottie対応表
具体的な対応状況は、Lottieの公式サポートマトリクスで確認できます。使いたい機能と対象プラットフォームを、実装前に照らし合わせます。

サポート外の機能

例：自動方向 / Auto Orient

  • Web：想定通り
  • Android：サポートなし
  • iOS：サポートなし
  • Lottie Issue (Open)
  • Lottie android Issue (Closed)

「対応しているか」を、プラットフォームごとに確認するのが必要

例としてAuto Orientを見ます。After Effectsで動いても、再生側が対応していなければ端末で結果が変わります。 「対応しているか」を、プラットフォームごとに確認するのが必要

チェックリスト

想定通りに動かすために

  1. 素材作成段階：サポートマトリックスをデザインと共有
  2. 素材取り込み段階：Web Previewだけでなく、スマホでも確認
  3. 想定通りでない場合：デザイン側と相談し、素材を修正
  4. 効率化：JSONや.lottieを最適化し、読み込みと描画の負荷を下げる
実装前に対応状況を確認し、書き出し後は実機で確認します。問題があれば別の表現を検討し、最後に最適化します。
